# Simple-Calculator
A basic calculator built using Python and Tkinter that performs addition, subtraction, multiplication, and division through a simple graphical interface.

Basic Calculator

This project is a simple calculator created using Python and Tkinter.

Features:
Addition, subtraction, multiplication, and division
Number buttons (0–9)
Decimal point support
Clear button to reset the input
Equals button to calculate results
Displays error messages for invalid calculations

Python Concepts Used:
Functions
Variables
Tkinter GUI
Buttons and input fields
Frames and grid layout
Try/except statements
